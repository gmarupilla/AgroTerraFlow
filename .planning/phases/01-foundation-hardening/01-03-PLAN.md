**1. Add MC zero-variance test:**

When all kriging standard deviations are zero, MC draws degenerate to point estimates and CI width collapses to zero. This test needs to exercise the MC block in pipeline.py with zero-variance data.

Strategy: Use `synthetic_raster` and `synthetic_climate_csv_dense` (which trigger kriging), but mock or patch the kriging std output to return all zeros. Alternatively, if the test infrastructure already runs a full pipeline with kriging, check if there's a way to force zero std.

Simpler approach: Run a kriging pipeline and verify the MC code path handles the result. If the existing dense fixture produces non-zero std, use monkeypatching on `ClimateInterpolator.interpolate` to return a DataFrame with `*_krig_std` columns set to 0.0.

```python
def test_mc_zero_variance_ci_collapsed(
    tmp_path, synthetic_raster, synthetic_climate_csv_dense, monkeypatch
):
    """When kriging std is zero everywhere, MC CI width must collapse to zero."""
    import numpy as np

    # Patch ClimateInterpolator.interpolate to zero out krig_std columns
    _orig_interpolate = None

    def _zero_std_interpolate(self, lats, lons):
        result = _orig_interpolate(self, lats, lons)
        for col in result.columns:
            if col.endswith("_krig_std"):
                result[col] = 0.0
        return result

    from terraflow.climate import ClimateInterpolator
    _orig_interpolate = ClimateInterpolator.interpolate

    monkeypatch.setattr(ClimateInterpolator, "interpolate", _zero_std_interpolate)

    cfg_path = _write_kriging_config(
        tmp_path / "cfg.yml", synthetic_raster, synthetic_climate_csv_dense,
        tmp_path / "out", uncertainty_samples=50,
    )
    df = run_pipeline(cfg_path)

    assert "score_ci_low" in df.columns
    assert "score_ci_high" in df.columns
    np.testing.assert_array_almost_equal(
        df["score_ci_low"].to_numpy(), df["score_ci_high"].to_numpy(), decimal=9
    )
```
