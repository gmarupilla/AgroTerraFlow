# H3 Export Demo

This page renders the H3 Export demo notebook, which demonstrates TerraFlow's
H3-indexed export workflow using synthetic data.

Topics covered:

- Converting suitability results to H3 hexagonal cells with `to_h3()`
- Comparing results at different H3 resolutions (fine vs coarse)
- CLI equivalent: `terraflow export --format h3 -c config.yml`
- Visualization with DeckGL and Kepler.gl

See also: [H3 Export documentation](../h3-export.md)
